Physics-Informed Neural Network (PINN) for Rock Slope Stability Analysis

## Overview
This repository contains the implementation of a Physics-Informed Neural Network (PINN) designed to predict the Factor of Safety (FoS) for rock slopes in the Amran Quarries. The model incorporates physical laws (Gle/Morgenstern-Price method) to improve prediction accuracy and generalization compared to traditional machine learning models like Random Forest.

## Dataset
The dataset (`PINN_Dataset.csv`) consists of 350 samples with the following features:
- Cohesion
- Friction Angle
- Slope Height
- Slope Angle
- Unit Weight
